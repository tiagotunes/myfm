# My FM

My FM is a mobile application designed for Football Manager players.

It allows users to manage their team, squad and tactics directly from
their mobile device.

This project focuses on:

- Squad management
- Tactical setup
- Save versioning

It does not aim to simulate matches or replace the Football Manager game.

## Tech Stack

- Flutter
- Dart
- Riverpod
- REST API backend

## Status

This project is currently in early development.
