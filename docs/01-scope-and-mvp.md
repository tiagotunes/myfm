# Scope and MVP Definition

This document defines what is included and excluded from the initial
version of the application.

## Included in MVP

- User authentication
- Online persistence
- Squad management
- Tactical formation editor
- Save management (create, edit, duplicate)

## Explicitly Out of Scope

- Match simulation
- Social features (likes, comments, feeds)
- Multiplayer or challenges
- Official Football Manager API integration

Any feature not listed in the MVP must be consciously added later.
